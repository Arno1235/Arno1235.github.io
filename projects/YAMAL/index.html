YAMAL

Yet Another Messaging and Asynchronous Launch

Just a small project inspired by ROS. [discontinued]

description:

YAMAL is a lightweight Python framework designed for easily running nodes in parallel and facilitating communication between them using YAML launch files.
Inspired by the functionality of ROS (Robot Operating System), YAMAL aims to provide a streamlined and minimalistic alternative for applications that require parallel processing and inter-node communication.
