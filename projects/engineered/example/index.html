This folder is the template. Duplicate it, drop files in assets/, and edit this HTML. Home lists one row per project; empty tiers stay as headers with no rows.

Layout is the v2 document: headings, paragraphs, tables, hr, pre, images. No classes. The stylesheet is fourteen element defaults plus a dark theme and a mobile fold.
