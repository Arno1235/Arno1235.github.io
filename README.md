# arno1235.github.io

Static HTML. Open `index.html`. No build, no packages.

## Add a project

1. Copy `projects/engineered/example/` to `projects/<tier>/<slug>/`.
   Tiers: `engineered`, `vibed`, `archived`.
2. Put images and other files in that folder’s `assets/`.
3. Edit the copy’s `index.html` (title, text, figures, image `src`).
4. Add one row under the matching `<h3>` tier on the home page.

The example page shows every block the layout supports. Delete the blocks you do not need. Empty tiers can stay as a heading with no rows under them.
