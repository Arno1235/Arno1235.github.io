# arno1235.github.io

Static HTML. Open `index.html`. No build, no packages.

## Add a project

1. Copy `projects/engineered/example/` to `projects/<tier>/<slug>/`.
   Tiers: `engineered`, `vibed`, `archived`.
2. Put images and other files in that folder’s `assets/`.
3. Edit the copy’s `index.html` (title, text, tables, image `src`).
4. Add one row to the matching tier table in the root `index.html`.

The example page shows every block the layout supports. Delete the blocks you do not need. Empty tiers can stay as a header row with no projects under them.
